## 4. Theory
FastAPI is a modern, high-performance web framework for building APIs with Python based on standard Python type hints:

1. **ASGI vs WSGI**:
   Traditional Python frameworks (such as Flask and Django) historically used WSGI (Web Server Gateway Interface), which is synchronous. FastAPI is built on Starlette and uses ASGI, providing native support for asynchronous event-loop concurrency.
2. **Pydantic Schemas**:
   Pydantic performs data parsing and runtime validation using Python type annotations. It automatically validates incoming JSON payloads, rejects malformed inputs with 422 Unprocessable Entity errors, and serializes output responses according to `response_model` definitions.
3. **RESTful Architecture Principles**:
   - Resources are represented by nouns in URIs (`/students`).
   - HTTP verbs dictate actions:
     - `GET`: Retrieve resource(s).
     - `POST`: Create a new resource.
     - `PUT`: Replace or update an existing resource.
     - `DELETE`: Remove a resource.
   - Status codes clearly reflect transaction outcomes (`201` for creation, `204` for successful deletion with no body, `404` for missing entities).
4. **Interactive Documentation**:
   FastAPI parses route definitions, Pydantic models, and type hints to automatically generate OpenAPI schemas accessible via Swagger UI (`/docs`) and ReDoc (`/redoc`).

## 5. Implementation
The project resides in `Theory/FastAPI/`:
- **[fastapi-project/main.py](file:///Users/anujsharma/Desktop/Backend/Backend-Development/Theory/FastAPI/fastapi-project/main.py)**:
  Full application source code implementing models and endpoints:

  1. **Data Models**:
     ```python
     from pydantic import BaseModel
     from typing import Optional, List

     class Student(BaseModel):
         id: int
         name: str
         branch: str

     class StudentCreate(BaseModel):
         name: str
         branch: str
     ```

  2. **In-Memory Storage**:
     ```python
     students: List[Student] = [
         Student(id=1, name="Anuj", branch="CSE"),
         Student(id=2, name="Diya", branch="ECE"),
         Student(id=3, name="Rohan", branch="IT"),
     ]
     next_id = 4
     ```

  3. **REST Endpoints**:
     - `GET /students`: Lists all students, with optional branch filtering:
       ```python
       @app.get("/students", response_model=List[Student])
       def list_students(branch: Optional[str] = Query(None)):
           if branch:
               return [s for s in students if s.branch.upper() == branch.upper()]
           return students
       ```
     - `GET /students/{student_id}`: Fetches a single student by ID or raises 404:
       ```python
       @app.get("/students/{student_id}", response_model=Student)
       def get_student(student_id: int):
           for student in students:
               if student.id == student_id:
                   return student
           raise HTTPException(status_code=404, detail="Student not found")
       ```
     - `POST /students`: Inserts a new student record returning status 201:
       ```python
       @app.post("/students", response_model=Student, status_code=201)
       def create_student(student: StudentCreate):
           global next_id
           new_student = Student(id=next_id, **student.model_dump())
           students.append(new_student)
           next_id += 1
           return new_student
       ```
     - `PUT /students/{student_id}`: Updates name and branch of an existing student record:
       ```python
       @app.put("/students/{student_id}", response_model=Student)
       def update_student(student_id: int, student: StudentCreate):
           for i, existing in enumerate(students):
               if existing.id == student_id:
                   updated = Student(id=student_id, **student.model_dump())
                   students[i] = updated
                   return updated
           raise HTTPException(status_code=404, detail="Student not found")
       ```
     - `DELETE /students/{student_id}`: Deletes student record returning status 204:
       ```python
       @app.delete("/students/{student_id}", status_code=204)
       def delete_student(student_id: int):
           for i, student in enumerate(students):
               if student.id == student_id:
                   students.pop(i)
                   return
           raise HTTPException(status_code=404, detail="Student not found")
       ```

  4. **Server Execution**:
     ```python
     if __name__ == "__main__":
         uvicorn.run("main:app", host="127.0.0.1", port=5000, reload=True)
     ```

## 10. Viva Questions
**Q1: How does FastAPI achieve higher performance compared to traditional frameworks like Flask?**  
**Ans:** FastAPI is built on Starlette and Pydantic, running on the ASGI standard with Uvicorn. It supports native asynchronous (`async`/`await`) non-blocking I/O and compiles data validation models directly via Python type hints.

**Q2: What is the purpose of Pydantic models in FastAPI?**  
**Ans:** Pydantic models define expected request and response data structures, automatically parse and validate input data types, return clear error messages on invalid input, and serialize Python objects into JSON.

**Q3: What HTTP status code is returned when a Pydantic validation error occurs?**  
**Ans:** FastAPI automatically returns HTTP `422 Unprocessable Entity` with a detailed JSON response detailing which fields failed validation and why.

**Q4: Why is HTTP status 204 used for DELETE operations instead of 200?**  
**Ans:** HTTP `204 No Content` indicates that the server successfully fulfilled the request and that there is no additional content to send in the response payload.
