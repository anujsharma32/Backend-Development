Part A — Conceptual Questions

1. What is jsonb in PostgreSQL, and how does it differ from the plain json type?

PostgreSQL provides two types for storing JSON data: json and jsonb. The json type stores JSON as text, while jsonb stores JSON in a decomposed binary format. Because jsonb is parsed and converted into an internal binary representation when it is stored, PostgreSQL can process its keys and values more efficiently during queries.

The main advantage of jsonb is its query and indexing capability. PostgreSQL can create indexes such as GIN indexes on jsonb columns, which can make searches for JSON keys and key-value pairs much faster. The trade-off is that writing or updating jsonb can require additional processing because PostgreSQL has to convert the input JSON into its binary representation.

The normal json type can be useful when the original formatting or key order of the JSON document needs to be preserved. However, jsonb is generally more useful when an application frequently searches or filters JSON data.
