
# Experiment 07: ES6 and DOM Manipulation

## Objective
To understand ES6 features and learn how to select and modify HTML elements using JavaScript DOM methods.

## Requirements
- Visual Studio Code
- HTML
- JavaScript
- Google Chrome

## Theory
ES6 introduced features such as let, const, arrow functions, template literals, and enhanced object syntax.

The Document Object Model (DOM) represents an HTML document as a tree of objects. JavaScript can select elements and change their content and styles.
