
# Experiment 08: Event Handling and Interactive To-Do List

## Objective
To understand JavaScript event handling and implement an interactive To-Do List application.

## Requirements
- Visual Studio Code
- HTML
- CSS
- JavaScript
- Google Chrome

## Theory
Events are browser actions such as clicks and key presses. JavaScript uses event listeners to respond to these actions.

The application uses click and keyboard events, DOM element creation, classList, array methods, and event delegation.

## Source Code
The source code is available in index.html and app.js.

## Output

## Result
The interactive To-Do List was implemented and tested. Tasks can be added, marked as completed, and deleted using event listeners.
